01 ソーステキスト 入力すると自動描画
02 シーケンス図 ドラッグで編集


区切り追加：図を右クリック → divider。ダブルクリックで文字を編集。
分岐追加：図を右クリック → fragment → alt。枠内の生命線から矢印を追加できます。alt枠内で右クリックするとfragmentにelseが表示されます。条件はダブルクリックで編集。altの上端・下端を上下にドラッグして囲む範囲を変更できます。
activation追加：図を右クリック → activation → 開始／終了を選択。
図をクリックすると赤く強調し、対応するソース行を選択します。
注釈追加：図を右クリック → note → 配置を選択 → コメント入力 → OK。単独の注釈は上下左右ドラッグで配置変更（近い参加者へ吸着）。複数参加者の注釈は左右のつかみを参加者へドラッグして対象変更。ダブルクリックでも対象を選択できます。選択してDeleteで削除。
矢印追加：破線の生命線から別の生命線へドラッグ（Shiftで破線矢印）。自己メッセージ：同じ生命線上で下へドラッグ → コメント入力 → OK（例：c->c:info）。
矢印の両端のつかみを参加者へドラッグすると接続先を変更。
並べ替え：参加者の箱を左右に／メッセージを上下にドラッグ。文字の編集：タイトル・参加者・メッセージをダブルクリック。メッセージを選択してDeleteで削除。
対応構文・保存についてtitle タイトル ／ participant a ／ participant "表示名" as a ／ a->b:info ／ a-->b:reply ／ a<--b:reply
→、← の実線・破線、自己メッセージ、外部端点 [ と ]、コメント（# または //）、文字中の \n に対応。noteの左・右・上・複数参加者に対応。activate・deactivate・deactivateafterにも対応。alt・else・endにも対応。loop等は未対応でエラー表示します。元サイトの全構文互換ではありません。ソースを残す場合は左側のテキストをコピーして保管してください。再読み込みすると初期例に戻ります。外部通信・サーバー不要。

Privacy Policy
Sequence Sketch Local のデータの取り扱いについて（2026年10月18日）
図のデータと情報収集
本アプリは、入力したソーステキスト、参加者名、コメントおよび作成した図をブラウザ内で処理します。これらを開発者や外部サーバーへ送信・収集する機能はありません。アクセス解析、広告、追跡用Cookie、外部CDNは使用していません。
保存とオフライン利用
編集内容はページを開いている間のメモリ上で扱い、アプリによる自動保存やCookie・localStorageへの保存は行いません。SVG・PNGは利用者が選択した保存先へ書き込みます。ローカルのHTMLファイルでは、作図のためのネット接続は不要です。
外部リンクとGitHub Pages
タイトルなどの外部リンクを開くと、リンク先への通信が発生し、そのサービスのプライバシーポリシーが適用されます。GitHubやGitHub Pages上でページを閲覧する場合、配信元のGitHubがアクセスに伴う情報を取り扱います。GitHub Pagesではセキュリティ目的でIPアドレスを記録すると説明されています。これはアプリによる図のデータ収集とは別です。
GitHub Pagesのデータ収集について ／ GitHub Privacy Statement
お問い合わせ・変更
不明点は プロジェクトのIssues へお知らせください。公開Issueには機密情報や個人情報を含めないでください。機能やデータの取り扱いを変更した場合は、この説明も更新します。
