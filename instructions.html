Sequence Sketch Local — Instructions

テキストとマウスの両方で編集できる、ローカルで完結するシーケンス図エディターです。SequenceDiagram.org風の構文に一部対応した独立した試作品です。全構文互換ではありません。

エディターを開く ／ 構文 ／ Privacy Policy ／ GitHub

起動と保存

sequence-editor.htmlをEdgeまたはChromeで開いてください。サーバーやインストールは不要です。作図処理はブラウザ内で動きます。この説明書も同じフォルダーに置くとオフラインで読めます。

メニューは「追加」「SVG保存」「PNG保存」「拡大」「縮小」です。「追加」は未使用の識別名で参加者を追加します。画像保存では対応ブラウザの保存ダイアログを使用します。表示倍率は25～300％です。

ソースの自動保存はありません。再読み込み・終了の前に、左側のテキストをコピーして保管してください。次回は左側へ貼り付けます。

マウス操作

操作結果
生命線から別の生命線へドラッグコメント入力後に矢印を追加。Shiftで破線。
同じ生命線上で下へドラッグ自己呼び出しを追加。
図形をクリック赤く強調し、対応するソース行を選択。
文字や図形をダブルクリック編集ダイアログを表示。Enterで改行、Ctrl＋Enterで更新。
参加者の箱を左右へドラッグ参加者を並べ替え。
矢印の中央を上下へドラッグソース行を移動して順序を変更。
矢印の端を参加者へドラッグ送信元・送信先を変更。つかみの四角は透明。
noteの中央をドラッグ単独noteの配置や上下の順序を変更。
複数参加者のnoteの左右端をドラッグ対象の参加者を変更。
altの上端・下端を上下へドラッグ囲む範囲とalt・end行の位置を変更。
矢印・noteを選択してDelete対象を削除。
Ctrl＋Z／Ctrl＋Shift＋Z元に戻す／やり直す。

下へスクロールすると、参加者の箱を上端に固定表示します。固定表示した箱は編集できません。画像出力には固定表示を含めません。

右クリックメニュー

  • note：left of、right of、over、複数参加者のover。
  • activation：activate、deactivate、deactivateafter。
  • fragment → alt：条件を入力してaltとendの空枠を追加。
  • fragment → else：alt枠内だけ表示。条件を入力して点線の分岐を追加。入れ子では最も内側の枠が対象。
  • divider：文字入りの区切り線を追加。

対応する主な構文

title サンプル
participant a
participant "表示名\n２行目" as b

a->b:リクエスト
activate b
b-->a:応答
deactivate b

note left of a:左の注釈
note right of a:右の注釈
note over a:注釈
note over a,b:複数参加者の注釈\n２行目

alt 成功
a->b:通常処理
else 失敗
b->a:エラー
end

==区切り==

a->a:自己呼び出し
activate a
deactivateafter a

[->a:左の外部から
a<-]:右の外部から
a->]:右の外部へ

# これはコメント
// これもコメント

participantのaliasはソースで使う識別名、long nameは図に表示する名前です。大文字・小文字を区別します。表示名やコメントの改行はソース上では \n と書きます。

実線・破線、左右方向の矢印、開いた矢印（->>など）、自己呼び出しに対応します。activateは直前要素の終了位置から開始し、deactivateは直前要素の位置で終了、deactivateafterは少し下で終了します。終了指定のない実行区間は図の下端まで表示します。

左側には行番号を表示します。構文エラーは赤い×で示し、マウスを合わせると理由、クリックすると対象行を表示します。box・alt以外のfragment・space・装飾構文などは未対応です。

Privacy Policy

更新日：2026年10月18日

本アプリは入力したソーステキスト、参加者名、コメント、図をブラウザ内で処理し、開発者や外部サーバーへ送信・収集しません。アクセス解析、広告、追跡用Cookie、外部CDNは使用しません。

編集内容はページを開いている間のメモリ上で扱い、自動保存やCookie・localStorageへの保存は行いません。SVG・PNGは利用者が指定した保存先へ書き込みます。ローカルファイルでの作図にネット接続は不要です。

外部リンクを開くと、そのリンク先への通信が発生し、そのサービスのプライバシーポリシーが適用されます。GitHub／GitHub Pagesで閲覧する際のアクセス情報はGitHubが取り扱います。GitHub Pagesはセキュリティ目的でIPアドレスを記録すると説明しています。アプリが図のデータを収集することとは別です。

GitHub Pagesのデータ収集 ／ GitHub Privacy Statement

お問い合わせは プロジェクトのIssues へ。公開Issueには機密情報や個人情報を含めないでください。機能やデータの取り扱いを変更した場合は、この説明も更新します。
