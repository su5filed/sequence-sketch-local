Sequence Sketch Local
ローカルで完結するシーケンス図エディター（図のデータを外部へ送信・収集しません）

■ 起動
ZIPを展開し、sequence-editor.html をEdgeやChromeで開いてください。
インストール、ローカルサーバー、インターネット接続は不要です。

■ 基本操作
・左側のテキストを編集すると、右側の図を更新します。
・生命線から別の生命線へドラッグすると、コメント入力後に矢印を追加します。
・Shiftを押しながらドラッグすると破線の矢印を追加します。
・図形をクリックすると赤く強調し、対応するソース行を選択します。
・図形や文字を左ボタンでダブルクリックすると編集画面を開きます。
・編集画面ではEnterで改行できます。ソースには \n として保存します。
・参加者はalias（識別名）とlong name（表示名）を編集できます。
・aliasを変更すると、矢印とnoteの参照先も更新します。
・参加者の箱は左右、矢印の中央は上下へドラッグして並べ替えできます。
・矢印の両端を参加者へドラッグすると接続先を変更できます。
・図を右クリックし、noteメニューから注釈を追加できます。
・単独のnoteは上下左右へドラッグできます。配置は参加者に吸着します。
・複数参加者にまたがるnoteは、左右端を参加者へドラッグして対象を変更できます。
・端のつかみは透明です。端にマウスを合わせるとカーソルが変わります。
・矢印やnoteを選択してDeleteキーで削除できます。
・「元に戻す」「やり直す」に対応しています。

■ 保存
メニューは「追加」「SVG保存」「PNG保存」「拡大」「縮小」です。
「追加」で未使用の識別名のparticipantを1つ追加します。
SVGまたはPNGとして図を保存できます。画像出力は表示倍率に依存しません。
画像保存ではOS標準の保存ダイアログで保存先とファイル名を選択します。
この保存機能は対応するデスクトップ版EdgeまたはChromeで使用してください。
非対応のブラウザや埋め込み表示では、対応ブラウザで開く案内を表示します。
拡大・縮小は25%～300%です。
テキストの保存・読み込みボタンはありません。ソースをコピーして保管してください。
自動保存はありません。ページの再読み込みや終了前にソースを保管してください。

■ 対応する主な構文
title This is a title
participant a
participant "表示名\n２行目" as b
a->b:info
b-->a:reply
note left of a:注釈
note right of a:注釈
note over a:注釈
note over a,b:注釈\n２行目

実線・破線、逆方向、開いた矢印、自己メッセージ、# または // の行コメントに対応。
SequenceDiagram.orgの全構文互換ではありません。
activationも対応しています。右クリック → activationから対象の開始・終了を追加できます。
activate a         : 直前の図要素の位置から実行区間を開始
deactivate a       : 直前の図要素の位置で終了
deactivateafter a  : 直前の図要素より少し下で終了
入れ子にも対応。終了のない実行区間は図の下端まで表示します。
外部矢印は [（図の左端）、]（図の右端）を使用できます。
[->C:外部からCへ
C<-]:右側の外部からCへ
C->]:Cから右側の外部へ
[ と ] の参加者の箱や生命線は作成しません。Cとcは別の参加者です。
fragmentはaltに対応しています。右クリック → fragment → altで追加できます。
追加時は条件（初期値info）を入力し、alt 条件とendの空枠を追加します。
条件中の改行は \n として保存します。Ctrl+Enterでも更新できます。
altの上端・下端を上下にドラッグすると囲む範囲とソース上のalt/endの位置が変わります。
上端選択ではalt行、下端選択ではend行が選択されます。
枠の横幅は囲まれたメッセージ・注釈に合わせて調整します。
elseはalt枠内を右クリック → fragment → elseで条件を入力して追加できます。
alt枠外ではelseメニューは表示されません。入れ子では最も内側の枠が対象です。
elseはソースに入力して追加することもできます。
alt 条件1
a->b:処理
else 条件2
b->a:別の処理
end
条件は図上でダブルクリック編集できます。altの入れ子にも対応します。
dividerは右クリック → dividerで文字を入力して追加できます。
ソースは ==divider xxxx== の形式です。図の文字はダブルクリックで編集できます。
box、alt以外のfragment、space等は未実装です。
